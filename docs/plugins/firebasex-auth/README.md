# FirebasexAuth

Cordova plugin for Firebase Authentication - part of the modular cordova-plugin-firebasex family.

## Installation

```bash
ionic cordova plugin add cordova-plugin-firebasex-auth
npm install @awesome-cordova-plugins/firebasex-auth
```

**Plugin Repo:** [https://github.com/dpa99c/cordova-plugin-firebasex-auth](https://github.com/dpa99c/cordova-plugin-firebasex-auth)

## Supported Platforms

- Android
- iOS
