# FirebasexConfig

Cordova plugin for Firebase Remote Config - part of the modular cordova-plugin-firebasex family.

## Installation

```bash
ionic cordova plugin add cordova-plugin-firebasex-config
npm install @awesome-cordova-plugins/firebasex-config
```

**Plugin Repo:** [https://github.com/dpa99c/cordova-plugin-firebasex-config](https://github.com/dpa99c/cordova-plugin-firebasex-config)

## Supported Platforms

- Android
- iOS
