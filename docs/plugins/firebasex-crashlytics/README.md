# FirebasexCrashlytics

Cordova plugin for Firebase Crashlytics - part of the modular cordova-plugin-firebasex family.

## Installation

```bash
ionic cordova plugin add cordova-plugin-firebasex-crashlytics
npm install @awesome-cordova-plugins/firebasex-crashlytics
```

**Plugin Repo:** [https://github.com/dpa99c/cordova-plugin-firebasex-crashlytics](https://github.com/dpa99c/cordova-plugin-firebasex-crashlytics)

## Supported Platforms

- Android
- iOS
