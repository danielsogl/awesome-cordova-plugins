# FirebasexPerformance

Cordova plugin for Firebase Performance Monitoring - part of the modular cordova-plugin-firebasex family.

## Installation

```bash
ionic cordova plugin add cordova-plugin-firebasex-performance
npm install @awesome-cordova-plugins/firebasex-performance
```

**Plugin Repo:** [https://github.com/dpa99c/cordova-plugin-firebasex-performance](https://github.com/dpa99c/cordova-plugin-firebasex-performance)

## Supported Platforms

- Android
- iOS
