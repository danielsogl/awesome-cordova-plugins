# FirebasexCore

Cordova plugin providing the core Firebase Installations API and app lifecycle listeners -
a required dependency of every other plugin in the modular cordova-plugin-firebasex family.

## Installation

```bash
ionic cordova plugin add cordova-plugin-firebasex-core
npm install @awesome-cordova-plugins/firebasex-core
```

**Plugin Repo:** [https://github.com/dpa99c/cordova-plugin-firebasex-core](https://github.com/dpa99c/cordova-plugin-firebasex-core)

## Supported Platforms

- Android
- iOS
