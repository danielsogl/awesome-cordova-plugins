# FirebasexMessaging

Cordova plugin for Firebase Cloud Messaging - part of the modular cordova-plugin-firebasex family.

## Installation

```bash
ionic cordova plugin add cordova-plugin-firebasex-messaging
npm install @awesome-cordova-plugins/firebasex-messaging
```

**Plugin Repo:** [https://github.com/dpa99c/cordova-plugin-firebasex-messaging](https://github.com/dpa99c/cordova-plugin-firebasex-messaging)

## Supported Platforms

- Android
- iOS
