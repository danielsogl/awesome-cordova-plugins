# FirebasexFirestore

Cordova plugin for Cloud Firestore - part of the modular cordova-plugin-firebasex family.

## Installation

```bash
ionic cordova plugin add cordova-plugin-firebasex-firestore
npm install @awesome-cordova-plugins/firebasex-firestore
```

**Plugin Repo:** [https://github.com/dpa99c/cordova-plugin-firebasex-firestore](https://github.com/dpa99c/cordova-plugin-firebasex-firestore)

## Supported Platforms

- Android
- iOS
