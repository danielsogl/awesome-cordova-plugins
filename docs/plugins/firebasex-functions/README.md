# FirebasexFunctions

Cordova plugin for Firebase Cloud Functions - part of the modular cordova-plugin-firebasex family.

## Installation

```bash
ionic cordova plugin add cordova-plugin-firebasex-functions
npm install @awesome-cordova-plugins/firebasex-functions
```

**Plugin Repo:** [https://github.com/dpa99c/cordova-plugin-firebasex-functions](https://github.com/dpa99c/cordova-plugin-firebasex-functions)

## Supported Platforms

- Android
- iOS
